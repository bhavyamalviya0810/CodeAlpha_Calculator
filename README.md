# CodeAlpha_Calculator
A responsive calculator built using HTML, CSS, and JavaScript. Supports basic arithmetic operations, keyboard input, error handling, and a modern user-friendly interface.

# CodeAlpha Basic Calculator

A responsive calculator developed as part of the CodeAlpha Frontend Development Internship.

## Features
- Addition, subtraction, multiplication, and division
- Keyboard support
- Clear and backspace functionality
- Division-by-zero error handling
- Responsive design for mobile and desktop
- Modern and clean user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
